Letter-level positioned text

Every single character below — including spaces — is its own absolutely-positioned, unroled <span>. This is the extreme end of the same pattern as the word-level scenario: a fixed-layout page whose text layer places one glyph per element. Positions are computed at load time the same way, one character at a time.

Even split letter by letter, e.g. like this, reconstruction still reads it as ordinary prose. Mr. Kratzenstein would approve.
